# 2단계 목표: 범용 알고리즘 (2026-10-19 18:58 설정)

**공원 맵과 영역만 입력받아, 조건별로 사람이 손대지 않고 흥미도 Very High 코스터를 설계하는 알고리즘을 만든다. 성능은 개발에 쓰지 않은 조건에서 잰다.**

계기: 사용자 요청("테스트한 조건에서만 유효한 것 아닌가? 다양한 조건에 적용할 수 있는 범용 알고리즘을 원한다").

1단계 결과에서 조건별로 사람이 정해 준 부분은 다음과 같다.
- 영역은 직사각형이고, 역의 위치와 방향은 손으로 정했다.
- 시작 타원은 평평한 가장자리를 가정했고, 언덕 높이는 조건마다 골랐다(16×16은 4).
- 지형 정보는 게임에서 읽지 않고, 내가 만든 명세에서 가져왔다.
- 차종은 레이팅 코드를 읽고 내가 골랐다.
- 점수 설정(강도 상한, slack, 일정)은 실패를 보고 고쳤다.

범위: 돈, 토지 소유, 연구 제약은 1단계처럼 끈다(샌드박스). 영역 안의 기존 경치는 지우지 않는다.
